# 🍽️ Zomato Data Analysis Project (Python)

## 📌 Objective

The objective of this project is to analyze Zomato restaurant data to understand customer preferences, restaurant performance, pricing trends, and factors affecting ratings.

---

## 📁 Dataset

* **Source:** Zomato Restaurant Dataset (India)
* **Type:** FoodTech / Restaurant Data
* **Contents:** Restaurant name, ratings, votes, cost, online order, table booking, type

📌 The dataset includes restaurant-level information such as ratings, pricing, votes, and service availability, which helps in analyzing customer behavior and business performance ([Kaggle][1])

---

---

## 🔍 Key Steps Performed

### 1. Data Cleaning

* Handled missing values
* Converted rating column into numeric format
* Removed duplicates and unnecessary columns

### 2. Exploratory Data Analysis (EDA)

* Analyzed restaurant types and popularity
* Studied rating distribution
* Compared online vs offline ordering

### 3. Data Visualization

* Count plots for restaurant types
* Rating distribution histogram
* Votes vs restaurant category analysis
* Online order availability chart

---

## 📈 Key Insights

* 📌 Majority of restaurants belong to **Dining category**
* 📌 Restaurants with **higher votes tend to have better ratings**
* 📌 Many restaurants still **do not offer online ordering**
* 📌 Cost for two people plays a major role in customer choice
* 📌 Customer engagement (votes) is a strong indicator of popularity

📌 Analysis like this helps answer real business questions such as:

* Which restaurant type is most preferred?
* Does online ordering increase popularity? ([geeksforgeeks.org][2])
