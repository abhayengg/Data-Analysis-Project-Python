# 🎬 Netflix Data Analysis Project (Python)

## 📌 Objective

The objective of this project is to analyze Netflix movies and TV shows dataset to understand content trends, genre distribution, and factors influencing content availability on the platform.

---

## 📁 Dataset

* **Source:** Netflix Movies & TV Shows Dataset (Kaggle)
* **Type:** Entertainment / Streaming Data
* **Rows & Columns:** ~8800+ records, multiple features
* **Key Columns:** Title, Type, Director, Cast, Country, Release Year, Rating, Duration, Genre

---

## 🛠 Tools & Technologies Used

* Python 🐍
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## 🔍 Key Steps Performed

### 1. Data Cleaning

* Handled missing values in director, cast, and country columns
* Removed duplicates
* Converted date and duration columns into usable format

### 2. Exploratory Data Analysis (EDA)

* Compared Movies vs TV Shows distribution
* Analyzed content growth over years
* Studied genre-wise and country-wise distribution

### 3. Data Visualization

* Movies vs TV Shows comparison chart
* Year-wise content addition trend
* Top genres analysis
* Country-wise content distribution

---

## 📈 Key Insights

* 📌 Netflix has **more Movies than TV Shows**
* 📌 Content addition increased significantly after 2015
* 📌 Most content is produced in **USA and India**
* 📌 Popular genres include **Drama, Comedy, and International content**
* 📌 TV Shows usually have multiple seasons, while Movies dominate in count
