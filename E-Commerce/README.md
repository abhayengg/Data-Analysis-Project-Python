# 🛒 E-Commerce Data Analysis Project (Python)

## 📌 Objective

The objective of this project is to analyze E-Commerce transaction data to identify sales trends, customer behavior, and key business insights that can help improve revenue and decision-making.

---

## 📁 Dataset

* **Source:** E-Commerce Dataset
* **Type:** Sales / Transaction Data
* **Contents:** Orders, Customers, Products, Revenue, Quantity, Category

---

## 🛠 Tools & Technologies Used

* Python 🐍
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## 🔍 Key Steps Performed

### 1. Data Cleaning

* Removed missing and null values
* Handled duplicate records
* Converted date and numeric columns properly

### 2. Exploratory Data Analysis (EDA)

* Analyzed sales trends over time
* Studied category-wise and product-wise performance
* Evaluated customer purchasing behavior

### 3. Data Visualization

* Sales trend (time series)
* Category-wise revenue distribution
* Top products analysis
* Customer segmentation charts

---

## 📈 Key Insights

* 📌 **Top Selling Category** contributes the highest revenue
* 📌 Few products generate **majority of total sales (Pareto Principle 80/20)**
* 📌 Sales show **seasonal trends and peaks during specific periods**
* 📌 Some customers contribute to **high repeat purchases**
* 📌 Discounts and pricing strategies directly impact sales volume
